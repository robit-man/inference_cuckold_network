Run any OpenAI-compatible local server. Keep the model on hardware you own; this page discovers it and optionally advertises it to peers.
Ollama · easiest
Install Ollama, pull any model you want, then allow this HTTPS origin if needed.
ollama pull MODEL_NAME OLLAMA_ORIGINS="ORIGIN_HERE" ollama serve
Default endpoint: http://127.0.0.1:11434
llama.cpp · GGUF
Download a GGUF, then expose llama-server. For LAN use, bind to 0.0.0.0 and restrict CORS to this page's exact origin.
./llama-server \ -m /path/model.gguf \ --host 0.0.0.0 \ --port 8080 \ --cors-origins "ORIGIN_HERE"
Default probe: http://127.0.0.1:8080
vLLM · GPU server
Best for high-throughput CUDA/ROCm nodes. Do not expose an unauthenticated vLLM server directly to the public Internet.
vllm serve MODEL_ID \ --host 0.0.0.0 \ --port 8000 \ --allowed-origins '["ORIGIN_HERE"]'
Default probe: http://127.0.0.1:8000

LAN server checklist
1. Bind the inference server to a LAN interface.
2. Configure CORS for this page's HTTPS origin.
3. Use the server's private IP in “Inference engines.”
4. Grant browser Local Network Access when prompted.
5. Keep your OS firewall enabled and expose only the inference port on trusted LANs.
What this file is
A zero-backend browser node. Static hosting supplies only this HTML; peer discovery is performed over public decentralized signaling and inference traffic travels peer-to-peer.
Data path
browser │ ├─ local fetch ─────► Ollama / llama.cpp / vLLM │ └─ WebRTC ─────────► peer browser │ └─ local inference engine
Discovery path
HTTPS static page │ Trystero signaling │ public Nostr relays │ WebRTC handshake │ direct encrypted data channel
Browser security intentionally prevents arbitrary raw LAN scanning/mDNS. The page therefore probes standard localhost ports and user-specified LAN endpoints instead of pretending to enumerate devices it cannot legally see.
Scale strategy
SHARDED mode joins a stable home shard plus a rotating exploration shard. This keeps WebRTC degree bounded while still exposing nodes to changing parts of the population.
